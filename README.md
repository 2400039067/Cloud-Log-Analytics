# Cloud Logging Sink to BigQuery for Log Analytics

# Project Overview
This project focuses on collecting, exporting, storing, and analysing cloud logs using Google Cloud Platform. Cloud Logging is integrated with BigQuery through a Log Sink to enable centralized log analysis using SQL queries.

# Objectives
- Collect cloud application and system logs.
- Configure a Cloud Logging Sink.
- Export selected logs to BigQuery.
- Analyse log data using SQL queries.
- Identify errors and monitor cloud activities.

# Technologies Used
- Google Cloud Platform (GCP)
- Cloud Logging
- Cloud Log Router
- BigQuery
- SQL
- Identity and Access Management (IAM)
- GitHub

# Project Architecture

Cloud Resources → Cloud Logging → Log Router / Sink → BigQuery → SQL Queries → Log Analytics

A centralized cloud log analytics solution that helps monitor activities, identify errors, and analyse log data efficiently.
